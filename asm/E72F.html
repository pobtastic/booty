E72F: Write Game Sprite Buffer
Used by the routines at Handler_Items, Handler_UnlockDoor and Handler_KeysAndLockedDoors.
Writes a sprite into the in-game room buffer. Clone of WriteSpriteBuffer.
Input
A Starting sprite ID
B Vertical position
C Horizontal position
D Height
E Width
WriteGameSpriteBuffer E72F PUSH AF Stash the registers this tile walk uses.
E730 PUSH BC
E731 PUSH DE
E732 PUSH HL
E733 DEC A Start one ID before the first tile so the increment lands on it.
E734 LD ($F336),A Write the tile ID to *ActiveSpriteID.
E737 LD A,E Remember the remaining width in *ActiveSpriteWidth.
E738 LD ($F335),A
WriteGameSpriteBuffer_0 E73B LD A,($F335) Reload the remaining width.
E73E LD E,A
E73F PUSH BC Stash the position and size.
E740 PUSH DE
E741 CALL ConvertCoordinateToBufferOffset Convert this tile into a room-buffer offset.
E744 POP DE Restore the position and size.
E745 POP BC
WriteGameSpriteBuffer_1 E746 LD A,($F336) A=*ActiveSpriteID.
E749 INC A Advance to the next tile ID.
E74A CP $00 Jump to WriteGameSpriteBuffer_2 if the tile ID wrapped.
E74C JR Z,WriteGameSpriteBuffer_2
E74E LD ($F336),A Write it back to *ActiveSpriteID.
WriteGameSpriteBuffer_2 E751 CALL PopulateGameRoomBuffer Write that tile into the game room buffer.
E754 DEC E Move one column across.

E757 DEC D Move on to the next row of tiles.
E758 JR Z,WriteGameSpriteBuffer_3 Jump to WriteGameSpriteBuffer_3 if every row is written.
E75A DEC B Move one row up.
E75B JR WriteGameSpriteBuffer_0 Jump to WriteGameSpriteBuffer_0.
WriteGameSpriteBuffer_3 E75D POP HL Restore HL, DE, BC and AF from the stack.
